# 🍰 わくわくケーキやさん

小学1年生向けの、注文に合わせてケーキを飾るWebゲームです。React + TypeScript + Viteで実装しています。

## 起動

Node.js 22.12以上（Node.js 24推奨）が必要です。

```sh
npm ci
npm run dev
```

表示されたURLをブラウザで開きます。同じWi-Fi内のスマートフォンやタブレットからは、ターミナルに表示されるNetwork URLを使えます。

## あそびかた

1. 「おみせを ひらく！」を押す。
2. お客さんの注文を見て、材料や「＋」をタップして飾る。
3. 多すぎる材料は「−」で減らす。
4. 「できた！」で届ける。違う場合は具体的なヒントを見て修正できる。
5. 1つ完成するごとにスター3こ。5人分作ると結果画面へ。

## 実装済み

- 開始・作成・完成・結果画面、5種類のお客さん
- 注文の自動生成、直前の注文の回避、未解放材料の除外
- 注文外の材料も含めた完全一致判定、増減ヒント
- 制限時間なし、材料ごとの増減操作、ケーキへの視覚的な反映
- スターとブルーベリー／星型チョコの解放
- 5段階の難易度。5注文ごとに直近5注文を評価し、4回以上一発成功で1段階上昇、3回以上修正で1段階低下
- LocalStorageでレベル、スター、完成数、一発成功数、修正回数、平均完成秒数、プレイ回数、直近100件の履歴、解放材料を保存
- 任意の効果音、軽いアニメーション、動きを減らすOS設定に対応
- スマートフォン・タブレット・PC、キーボード操作、ダイアログのフォーカス制御
- 保存不可・壊れた保存データでもプレイを継続

材料は1種類につき最大5こ。Level 5の注文は合計10〜15こです。各注文の完了時に報酬と履歴を確定するので、途中でおみせに戻っても獲得済みスターは残ります。作りかけのケーキは保存しません。成功時の重複操作による報酬の二重加算を防いでいます。

ブラウザ／端末間の同期はありません。ブラウザのサイトデータを削除すると進捗も消えます。登録、広告、解析、AI API呼び出しはありません。フォントはGoogle Fontsを使い、読み込めない場合は端末の日本語フォントに切り替わります。

## 検証

```sh
npm run build
npm test
npx playwright install chromium
npm run test:e2e
```

単体テスト11件、ブラウザテスト3件。注文の制約・正誤判定・難易度・保存復旧と、5注文の完了・スター解放・再読み込み・モバイル操作・保存不可時の動作を検証します。

## ビルドと公開

```sh
npm run build
npm run preview
```

出力先は`dist/`です。静的サイトのホスティングに配置できます。ビルドコマンドは`npm run build`、公開ディレクトリは`dist`、環境変数は不要です。本リポジトリへのpushだけでは自動公開しません。

## 構成

- `src/App.tsx`: 画面とゲーム進行
- `src/components/Cake.tsx`: SVGケーキとトッピング
- `src/game/engine.ts`: 注文生成・判定・難易度・履歴・保存
- `src/styles.css`: レスポンシブUI
- `src/game/engine.test.ts`: 単体テスト
- `e2e/game.spec.ts`: ブラウザテスト

MVPに加え、材料解放と履歴保存まで実装。AI注文生成、保護者画面、足し算・記憶・買い物モードなどは将来の拡張として未実装です。小学1年生によるユーザーテストは今後実施してください。
